# SAC Design Asset 보관소

이 폴더는 SAC 앱 디자인 소스를 보관합니다.
앱 런타임 asset (`app/flutter_app/assets/`)과 반드시 분리합니다.

## 폴더 구조

| 폴더 | 내용 |
|------|------|
| `stitch/` | Stitch 생성 화면, 스크린샷 |
| `claude_design/` | Claude Design 결과물 |
| `figma/` | Figma export / handoff |
| `references/` | 참고 이미지, 레이아웃 자료 |
| `exports/` | 최종 디자인 산출물 |

## 파일명 규칙

`YYYYMMDD_[화면명]_[버전]_[도구].확장자`

예: `20260605_dashboard_v1_stitch.png`
